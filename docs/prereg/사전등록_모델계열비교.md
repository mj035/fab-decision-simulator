# 사전등록 — 모델 계열 비교 실험 (PCA · 비트리 계열 · SMOTE)

> **실행 전 확정 문서.** 실행 후 수정 금지. 수정이 필요하면 고치지 말고 개정 이력에 남기고 승인받는다.
> 작성 시점 산출물: `results/model_cmp/thresholds.json` (기존 캐시에서 유도, 실험 미실행).
> **격리 원칙**: 정본 코드·결과·그림·보고서·시뮬레이터를 일절 수정하지 않는다.
> 신규 파일만 사용 — `src/model_cmp*.py`, `results/model_cmp/`.

## 0. 목적 — 무엇을 확인하고 무엇을 확인하지 않는가

**확인한다**: 동일한 leakage-free nested OOF 조건에서 **PCA와 비트리 모델 계열이
AUC·비용·walk-forward를 유의하고 실질적으로 개선하는지.**

**확인하지 않는다**:
- 논문(Nuhu et al. 2023)의 99.5~100% 성능 재현. 해당 논문은 §3.2.6에서 SMOTE를
  *"applied to the whole dataset, not just the training subset"* 이라고 **명시**하므로 일반화 성능이 아니다.
- 정본 모델의 즉시 교체. 본 실험은 **비교 보고**가 1차 산출물이며, 교체는 §5 조건을 모두 넘길 때만 **검토** 대상이다.

⚠️ **본 실험 결과는 자산 동결 이후 산출될 가능성이 높다.** 그 경우 동결 규칙에 따라
**한계 절·부록 보강으로만 처리**하며 정본을 교체하지 않는다.

## 1. 실험군 (최소 범위)

전처리·모델을 한꺼번에 바꾸면 무엇이 효과를 냈는지 분리할 수 없다. 요인을 나눈다.

| # | arm | 전처리 | 모델 | 분리하는 요인 |
|:--:|---|---|---|---|
| A0 | `base_lgbm` | 중앙값대치 → VarThr → 표준화 | LightGBM (정본 설정) | **기준선** (동일 코드경로 재계산) |
| A1 | `svc` | 위와 동일 | SVC (RBF) | **모델 계열**만 |
| A2 | `pca_rf` | 위 + PCA | RandomForest | PCA + 트리앙상블 |
| A3 | `pca_svc` | 위 + PCA | SVC (RBF) | PCA + 비트리 |
| B1 | `svc_smote` | A1 + SMOTE(fold 내부) | SVC (RBF) | **SMOTE 효과**(A1 대비) |
| B2 | `pca_svc_smote` | A3 + SMOTE(fold 내부) | SVC (RBF) | **SMOTE 효과**(A3 대비) |

- **A0는 반드시 재계산한다.** 캐시(`cms_seeds`)와 비교하면 코드 경로 차이가 교란된다 —
  AUC 튜닝에서 이미 겪은 문제다.
- SMOTE는 **A1·A3에 대한 대조군**으로만 붙인다. 트리 계열(A2)에는 붙이지 않는다 —
  SMOTE가 기하 민감 모델에서 더 크게 작용할 것으로 보아 그쪽에 자원을 집중한다.
- **k-NN 대치는 쓰지 않는다.** 근거: 본 프로젝트 5.2에서 대치 전략 8종을 동일 조건 비교했고
  0-채움 vs 중앙값이 8/15(53%, t=1.14)로 동전던지기였다. 대치는 이 데이터의 병목이 아니다.
  fold 내부 `KNNImputer` 250회는 비용만 크고 기대 이득이 없다. **이 결정을 한계에 명시한다.**

## 2. 하이퍼파라미터 — 실행 전 확정

### 2.1 SVC
```
kernel  = 'rbf'            (고정)
gamma   = 'scale'          (고정. StandardScaler 이후이므로 스케일 불변)
C       ∈ {0.1, 1, 10}     ← inner fold에서 AUC로 선택 (nested)
class_weight = 'balanced'  (고정. SMOTE 미적용 arm의 불균형 대응 — 정본 LGBM의 scale_pos_weight와 대응)
점수     = decision_function   ★ probability=True 사용 금지
```
**`probability=True`를 쓰지 않는 이유**: 내부에서 Platt 보정을 5-fold로 돌려 **비용이 5배**가 되고,
우리 커널은 확률이 아니라 **순위**만 필요하다(임계값은 격자 스윕으로 찾는다).
`decision_function`이 더 싸고 더 정직하다.

**C 탐색을 3개로 제한하는 이유**: LGBM 튜닝 결과가 **시나리오 A**(6 config nested 탐색에도 ΔAUC −0.003)였다.
이 데이터에서 하이퍼파라미터 탐색은 이득이 나는 지점이 아니라는 실측 근거가 있다.
탐색을 넓히지 않는 대신 **"탐색 범위를 3개로 제한했다"를 한계에 명시**하고,
`SVC를 충분히 튜닝하지 않았으므로 SVC의 상한을 주장하지 않는다`.

### 2.2 PCA
```
적합 위치 = 학습 fold 내부에서만 fit (전체 데이터 fit 금지)
n_components = 누적 설명분산 0.95를 만족하는 최소 성분 수   ← 주 설정
보고 항목    = fold별 선택된 성분 수의 평균·범위
```
- 논문은 0.99(→221 성분)를 썼다. **0.99는 사전 선언된 2차 설정**으로 두고,
  시간이 허용될 때만 추가 실행하며 **주 판정에는 쓰지 않는다.**
- PCA를 outer test에 적용할 때는 **학습 fold에서 적합된 변환만** 사용한다.

### 2.3 SMOTE — 적용 위치 (누수 방지의 핵심)
```
적용 대상 = 학습 부분집합에만.  대치 → 표준화 → (PCA) → SMOTE → 모델 적합
비적용 대상 = ① outer test  ② inner fold의 검증 부분  ③ 임계값 선택에 쓰는 inner OOF 예측
k_neighbors = 5,  sampling_strategy = 1.0 (완전 균형, 논문과 동일)
```
🔴 **임계값 선택은 반드시 SMOTE를 거치지 않은 원본 분포에서 한다.**
SMOTE된 균형 데이터에서 임계값을 고르면 실제 유병률(6.6%)이 아니라 50% 세계에 맞춰진 임계값이 나온다.
→ 학습은 SMOTE된 데이터로, **inner OOF 예측과 임계값 선택은 원본 held-out에서** 수행한다.

※ 참고: Nuhu et al.(2023) §3.2.6은 SMOTE를 *"applied to the whole dataset, not just the training subset"*
이라고 기술한다. 다만 **해당 논문의 임계값 선택 절차는 본문에 기술되어 있지 않아 확인되지 않았다** —
따라서 "논문이 이 지점을 어겼다"고 단정하지 않는다. 본 실험은 위 절차를 지킨다는 사실만 기록한다.

### 2.4 운영 정책의 정의 — **순위 기반** (SVC 척도 문제의 근본 해결)

```
정책        = "점수 상위 q% 검사"   (q = **목표** 검사율)
q 격자      = linspace(0.005, 0.995, 300)   ← inner·outer·전방에 동일 적용
순위 산출   = **각 모델 fit 내부에서만**. 서로 다른 fit의 점수를 합쳐 정렬하지 않는다.
동점 처리   = **cutoff 동점은 전부 포함**하고 실제 검사율을 기록
```

🔴 **동점을 안정 정렬로 끊지 않는 이유**: 안정 정렬은 결정론적이지만 동점 시 **원본 행 순서**를 우선한다.
SECOM의 행 순서는 **생산 순서**를 보존하므로(23차 시간축 복원) 시간이 보조 판단 기준으로 새어든다.
RF 확률은 이산적이라 동점이 많다. → **동점 전부 포함**으로 바꿔 행 순서 의존을 제거했다.

**실측 동점 초과폭**(실행 전 검증, n=313 모의):

| 점수 유형 | 고유값 | 실제−목표 중앙 | 최대 |
|---|:--:|:--:|:--:|
| 연속 (SVC margin 유사) | 313 | +0.000%p | +0.157%p |
| RF 500트리 유사 | 221 | +0.064%p | +1.104%p |
| 극단 이산 (21값) | 21 | +3.093%p | +12.315%p |

- 반올림 격자 한계는 ±0.5/n(≈±0.16%p)이므로, **실제 검사율이 목표보다 근소하게 작을 수도 있다**
  (엄밀히 "실제 ≥ 목표"는 성립하지 않는다). 이보다 큰 초과분이 동점 효과다.
- **arm 간 q는 완전히 동일한 운영점을 뜻하지 않는다**(이산성 차이). 다만 비용 커널은 **실제 혼동행렬**로
  비용을 계산하고, 비교는 **각 모델이 자기 비용최적 정책을 골랐을 때**의 비용으로 하므로 판정은 유효하다.
  실제 검사율과 동점 초과폭을 결과에 기록해 이 점을 드러낸다.

**왜 절대 임계값이 아닌가.** SVC `decision_function`은 fit마다 margin 척도가 다르다.
inner OOF 점수는 **3개의 서로 다른 inner fit**에서 나오고, outer 테스트 점수는 **네 번째 fit**
(outer train 전체)에서 나온다. 따라서 inner에서 만든 **숫자 임계값을 outer에 이전하면
같은 숫자가 같은 운영점을 뜻한다는 보장이 없다.** 이는 §3에서 "pooled 결합이 부적절하다"고
선언한 것과 같은 종류의 불일치다.

**q는 척도 불변이므로 이 문제가 사라진다.** inner에서 고른 q가 outer에서 동일한 운영 결정
(상위 q% 검사)을 뜻한다. 대안이던 fold 내부 calibration은 추가 적합이 필요해 비용이 크고,
단조 변환이라 순위를 바꾸지 않으므로 **순위 정책이 주는 것 이상을 주지 않는다.**
또한 q는 시뮬레이터가 실제로 운용하는 축(검사율)과 일치한다.

**검증 완료**(실행 전): 선형·표준화·sigmoid 변환에 대해 혼동행렬 불변, 카운트 항등식
(행 합 = n, 양성 합 = P) 성립, `CM.evaluate`의 스케일 assert 통과, 동점 결정론 확인.

⚠️ **비교 범위 제한**: 본 실험의 `base_lgbm`은 **순위 정책**으로 평가되므로
절대 확률 임계값을 쓰는 **정본 수치(31.0% 등)와 직접 비교하지 않는다.**
본 실험 내부의 arm 간 대응 비교에만 사용한다.

## 3. 평가 프로토콜

- 동일 50 seed, 동일 `StratifiedKFold(5, shuffle=True, random_state=seed)` → **모든 arm이 같은 fold를 본다**(대응 설계).
- 임계값은 학습 fold 내부 OOF(3-fold)에서만 선택. outer는 평가 전용.
- 비용은 정본 커널 `cost_model.CM.evaluate` 그대로. cl 2~64, cs=0, β=0.95, α=0.02.
- 손익분기는 "이후 단조유지" 규칙 사용. 단 **정의역은 프로토콜 부속**이므로
  본 실험 경로의 정의역을 별도 산출하고, 정본 `cl∈[2,64]`와 혼용하지 않는다.

**⚠️ 실행 전 구현 수정 4건 (리뷰어 지적 반영, 프로브 이전에 적용 완료)**

1. **전처리 적합 위치**: 중앙값 대치·분산 필터·표준화를 **각 training subset 내부에서만** fit한다.
   종전 구현은 outer train 전체에서 fit한 뒤 inner CV에 넣어 inner 검증분이 전처리 통계에 기여했다.
   **전역 상수열 제거도 폐지**하고 fold 내부 `VarianceThreshold`가 처리한다(입력은 열 필터를 거치지 않은 원본).
2. **정책 정의를 순위 기반으로 교체** (§2.4). 1차 결함은 inner·outer가 각각의 분위수 격자를 써서
   임계값 인덱스가 어긋난 것이었고, 이를 "inner 배열을 outer에 이전"으로 고쳤으나 **여전히 불일치**였다 —
   그 배열은 서로 다른 SVC fit의 margin에서 나온 값이기 때문이다. **정책을 상위 q% 검사로 정의**해
   척도 의존을 제거했다. 확률 모델·SVC 모두 동일한 q 격자를 쓴다.
3. **AUC 주지표 정의**: **outer fold별 AUC의 seed 내 평균**을 주지표로 한다.
   pooled OOF AUC는 **참고값으로만 병기**한다 — SVC `decision_function`은 fold마다 스케일이 달라
   fold 간 점수를 하나로 모아 순위를 매기는 것 자체가 부적절하다.
4. **재현·복구**: 캐시를 **원자적으로 저장**(tmp 기록 후 교체)하고, **finalize-only 모드**(`CMP_FINALIZE=1`)로
   신규 실행 없이 캐시만 집계·판정할 수 있게 한다. 집계 대상은 **모든 arm이 공통으로 보유한 연속 seed**
   (인덱스 0부터)로 한정한다. 캐시 로딩은 **핸들을 즉시 닫는다**(지연 핸들 누수 방지).
5. **본 실행 루프를 seed 우선으로** 한다(arm 우선 아님). 중단되어도 **모든 arm의 공통 연속 seed가
   함께 쌓이므로** §7-3 부분완료 판정이 가능해진다. arm 우선이면 중단 시 뒤쪽 arm이 통째로 비어 판정 불가다.
6. 🔴 **inner에서도 fit 간 점수를 합치지 않는다**(중대). 종전 구현은 3개 inner fit의 margin을 한 배열로 합쳐
   ① pooled AUC로 C를 고르고 ② 합친 배열을 전역 정렬해 상위 q%를 정했다.
   q는 **한 fit 내부에서만** 척도 불변이므로, 척도가 다른 fit들을 합쳐 정렬하면 margin 범위가 넓은 fold의
   표본이 과대 선택된다. → **inner fold별로 AUC·q별 혼동행렬을 각각 계산**하고,
   **C 선택 = fold AUC 평균**, **비용용 inner 행렬 = fold별 혼동행렬의 q별 합**으로 바꿨다.
   (outer AUC에서 pooled를 버린 것과 **동일 원칙을 inner에 적용**. 종전엔 outer에만 적용해 비일관이었다.)
   *검증: 척도가 다른 3 fold 모의에서 q=10% 기준 fold별합산 tp=4 vs pooled tp=1 — 실제로 달라진다.*
7. **동점 중립화**(§2.4). 검증: 이산 점수에서 행 순서를 5회 섞어도 혼동행렬 불변
   (종전 안정정렬 방식은 행 순서 변경 시 tp가 달라짐을 대조 확인).

## 4. 판정 기준 — 측정에서 유도 (`results/model_cmp/thresholds.json`)

⚠️ 앞서 구두로 제시했던 **"비용 2% 개선"은 근거 없는 임의값이었으므로 폐기**한다.
아래는 기존 캐시(50/29 seed)의 실측 잡음에서 유도한 값이다.

| 축 | 통계적 유의 | 실질적 개선 | 유도 근거 |
|---|---|---|---|
| **AUC** | 대응 ΔAUC 95%CI가 0을 배제 | **ΔAUC ≥ +0.02** | CI는 대응 SE(실측 ±0.0064). 0.02는 아래 ⚠️ 참조 |
| **비용** | cl 10~20 대응 비용차 95%CI가 0을 배제 | **베이스라인 대비 ≥ 3.5% 절대비용 감소** | 대응 비용차 CI 반폭 실측 최대 **1.59%**(cl 10~20)의 약 2배 |
| **전방** | — | **wf 스텝별 AUC가 −0.015를 넘어 악화되지 않을 것** | wf seed 잡음 실측치(학습셋 동일·seed만 변동 시 0.559 vs 0.544) |

🔴 **통계적 유의성은 반드시 대응(paired) CI로 판단한다. 개별 모델의 seed SD로 판단하지 않는다.**
실측이 이를 뒷받침한다 — 대응 CI 반폭 **±0.0064** vs 개별 seed SD **0.0118 / 0.0221**.
개별 SD를 쓰면 대응 설계의 정밀도를 버리는 것이고, 실제보다 보수적인 오판이 된다.

**ΔAUC 0.02의 역할과 출처**: 통계 기준이 아니라 **실질적 개선** 기준이다.
CI가 0을 배제해도 ΔAUC < 0.02이면 "유의하지만 실질적이지 않음"으로 보고한다.

⚠️ **출처 한계 명시**: 0.02는 **AUC 튜닝 사전등록에서 유도된 값이며, 그때의 AUC 정의는
pooled OOF AUC**였다(당시 seed sd 0.014의 약 1.4배). 본 실험의 주지표는 §3 수정 3에 따라
**fold별 AUC의 평균**으로 바뀌었고, 두 정의의 seed 변동 특성은 동일하지 않다.
0.02를 **재유도하지 않고 그대로 승계**하는 이유는, 결과를 본 뒤 기준을 재산출하면
사전등록의 의미가 훼손되기 때문이다. → **"pooled 기준에서 승계한 실질 기준"임을 결과 보고 시 병기**하고,
fold-mean 기준의 seed sd는 실행 후 **참고 정보로만** 보고한다(기준 변경에 사용하지 않는다).

## 4-bis. walk-forward 실행 규칙 (결과 확인 전 확정)

전방 축은 §5의 교체 검토 조건 중 하나이므로, **실행 규칙을 지금 고정**한다.

**대상**: §4의 AUC·비용 두 축을 모두 통과해 **"교체검토"로 분류된 arm에 한해** 실행한다.
통과 arm이 없으면 실행하지 않는다(자원 절약이지 결과 은폐가 아니며, 미실행 사실을 기록한다).
기준선 `base_lgbm`은 **비교를 위해 항상 함께** 실행한다.

**분할**: 시간축은 **행 인덱스(생산 순서)**. 정렬 금지. `wf_v2`·`fwd_cost`와 동일하게
Q1→Q2, Q1~2→Q3, Q1~3→Q4 3스텝.

**프로토콜**:
- 전처리·PCA·SMOTE·모델은 **각 학습 블록 내부에서만** fit (§3 수정 1과 동일 규칙).
- 정책은 **§2.4의 동일 q 격자**를 학습 블록과 전방 테스트 블록에 그대로 적용한다.
  각 모델 fit **내부에서** 점수 상위 q%를 검사하며, **절대 임계값 배열을 fit 간에 이전하지 않는다**.
  학습 블록의 inner 평가도 §3 수정 6에 따라 **fold별 혼동행렬 합산**으로 한다.
- SVC의 C는 학습 블록 inner fold에서 선택.
- **20 seed** (`fwd_cost` 정본과 동일). seed는 내부 임계값 선택 fold와 모델 난수만 바꾸며,
  **외부 시간 분할은 고정**되므로 분산은 과소추정이다 — 인용 시 병기한다.

**판정**:
- 지표는 **스텝별 전방 AUC**. 대응 비교(동일 seed·동일 블록)로 `arm − base_lgbm` Δ를 낸다.
- **악화 판정: 3스텝 중 어느 한 스텝이라도 대응 Δ의 95%CI 상한이 −0.015 미만이면 "악화"**로 보고
  해당 arm은 교체 검토에서 제외한다.
- −0.015는 wf seed 잡음 실측치다(`wf_v2` Q1~3→Q4에서 학습셋이 완전히 동일한데 seed만 바뀐 AUC 차 0.559 vs 0.544).
- **대조군(크기맞춤 무작위)은 실행하지 않는다.** Q1~3→Q4 스텝에서 학습셋과 풀이 일치해
  대조가 구조적으로 미정의임이 이미 확인되었고(26차 승인 ②), 본 실험의 판정에 필요하지 않다.

**보고**: 스텝별 AUC와 대응 Δ·CI를 표로 내고, Q2 구간은 **커널 권고 전략(원시 argmin)을 병기**한다 —
해당 구간은 정본 파이프라인에서 전수통과가 권고되므로 AUC만으로 해석하면 오도된다.

## 5. 교체 검토 조건

> **AUC · 비용 · 전방 3개 축을 모두 충족할 때만 교체를 검토한다.**
> AUC만 충족하면 **비교 결과로만 보고하고 교체하지 않는다.**

AUC 단독 기준으로 모델을 고르는 것은 헤드라인 3번("AUC 우위가 운영점 우위를 보장하지 않는다")과
정면으로 모순되므로 금지한다.

**교체가 검토 대상이 되더라도**, XAI 계층은 분리 유지한다:
- 공정 진단(무엇을 점검할까) = **LightGBM/SHAP, 원본 센서 공간** — S59·결측=신호·시간상관은 이 경로에 묶여 있다
- 단위 선별(어느 것을 검사할까) = 비용이 가장 낮은 모델
이 분리는 **결과를 보기 전에 선언**한다. 결과 후에 붙이면 사후 정당화가 된다.

## 7. 중단·부분완료 규칙 (결과 확인 전 확정)

1. **시간 프로브**: 각 arm의 첫 seed 소요시간을 측정해 총 예상시간을 출력한다.
   **총 예상 6시간 초과 시 자동 중단**하고 arm 축소를 요청한다(임의 축소 금지).
2. **캐시·재개**: `results/model_cmp/cache/{arm}_s{seed}.npz`. 중단되어도 완료분은 보존, 재실행 시 이어받는다.
3. **부분완료 판정**: 모든 arm이 **seed 인덱스 순 30개 이상** 완료 시에만 판정한다.
   사용 범위는 **인덱스 순 앞에서부터 공통 최소 개수**. **결과 기반 선별 금지.**
   30개 미만이면 판정하지 않고 "시도·미완"으로 보고한다. **판정 임계는 seed 수와 무관하게 불변.**
4. n < 50으로 판정한 경우 **"n=NN seed (사전등록 §7)"를 반드시 병기**한다.

## 8. 사전 선언 — 예상과 그 근거

결과 후 사후해석을 막기 위해 예상을 미리 적는다. **예상이 틀려도 기준은 바꾸지 않는다.**

- SMOTE 효과는 **불확실하다**. 임계값 최적화를 이미 수행하므로 이점 일부는 중복될 수 있으나,
  SMOTE는 학습 경계와 순위까지 바꾸므로 특히 **SVC 같은 기하 민감 모델에서는 트리보다 클 수 있다.**
  (초기에 "주로 임계값 문제"라고 축소했던 서술은 과했다 — 리뷰어 지적을 반영해 철회한다.)
- PCA는 전방 성능을 **악화시킬 소지**가 있다. 성분 축이 시간에 따라 회전하면 재보정 부담이 커진다.
  §4의 전방 기준을 넣은 이유가 이것이다.
- 양성 104건에서 AUC 표준오차가 ±0.03 수준이므로, **이보다 작은 계열 간 차이는 본 데이터로 검출되지 않는다.**
